# Music Artist Bio Sharing App

## Overview
A platform where users can create and share short biographical profiles for new music artists, helping to discover and promote emerging talent.

## Core Features

### Artist Bio Creation
- Form for adding artist information including:
  - Artist name (required)
  - Genre (required)
  - Short biography or background story (required)
  - Optional music platform links (Spotify, SoundCloud, YouTube, etc.)
  - Optional social media profile links
  - Artist photo or logo upload

### Artist Bio Display
- Gallery-style feed showing all submitted artist bios
- Each bio card displays:
  - Artist image
  - Artist name
  - Genre
  - Biography excerpt
  - Links to music platforms and social media

### Discovery Features
- Search functionality to find artists by name
- Filter artists by genre
- Browse all artists in chronological order (newest first)

### User Interface
- Clean, modern design
- Responsive layout optimized for desktop and mobile
- Intuitive navigation between create and browse sections

## Backend Data Storage
The backend must store:
- Artist profiles with all submitted information
- Uploaded artist images
- Music platform and social media links
- Genre categories for filtering

## Backend Operations
- Create new artist bio entries
- Retrieve all artist bios for the gallery feed
- Search artist bios by name
- Filter artist bios by genre
- Handle image uploads and storage
